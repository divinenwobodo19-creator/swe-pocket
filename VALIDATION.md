# Compact-stratum validation

Every one of the 24 mined compact tasks was replayed from scratch on
2026-11-10: clone the upstream repository, check out the task's `base_commit`,
apply `test_patch`, run the affected tests, then apply the gold `patch` and run
them again. The test target is the test file(s) the `test_patch` touches; when
the patch adds test functions, only those are selected with `-k`.

**Result: 21/24 tasks discriminate.** All 24 patch pairs apply cleanly. The
three exceptions (`parso_227`, `parso_233`, `parso_241`) are version-gating test
changes: their tests already pass at the base commit, so applying the gold patch
cannot turn a failure into a pass. They are kept for provenance and marked
`"discriminates": false` in `resources/compact_tasks.json`; exclude them
from any evaluation run.

Environment: Python 3.12, pytest 8.4.2, plus the upstream test dependencies
(`pretend`, `tomli-w`, `pytest-lazy-fixtures`, `wcwidth`, `sh`, `hypothesis`).
For `prettytable`, `src/prettytable/_version.py` was stubbed with
`__version__ = "0.0.0"` because the file is generated by the build backend.
